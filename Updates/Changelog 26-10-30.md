# 📑 Changelog 10/23/2026 - 10/30/2026

## 🟢 Status `Released`

## 💬 Patch Notes
This update gives the menus a brand new look, with a redesigned Main Menu, Armory, Shop, Profile and Map Vote. It also brings the new Smoke Grenade, 22 calling cards in the shop, an Armory you can open mid-match, smoother aiming sensitivity, toned-down Flashbangs and Concussion Grenades, and a big round of bug fixes.
________

## 📢 Features and Improvements

### ✅ `Feature` Smoke Grenade
- Tactical grenade type.

### 💄 `Cosmetic` Purchasable Calling Cards
- 22 new calling cards in the shop, purchasable with gold.

### 💄 `Cosmetic` Purchasable Universal Camos
- 8 new universal camos in the shop, purchasable with gold.

### 🔼 `Improvement` Added new "Operator Switch" button
- Allows you to preview your classes Globalist or Anarchist operator.

### 🔼 `Improvement` New Main Menu UI
- New modern style.

### 🔼 `Improvement` New Armory UI
- New modern style.

### 🔼 `Improvement` New Shop UI
- New modern style

### 🔼 `Improvement` New Profile UI
- New modern style.
- Now displays all your medals.

### 🔼 `Improvement` New Map Voting UI
- New modern style.

### 🔼 `Improvement` New Character Animations
- Pistols do a 1-handed sprint animation.
- You can see now other players throw grenades.

### 🔼 `Improvement` Armory is now accessible while deployed

### 🔼 `Improvement` Play Menu is now easier to use with a controller

### 🔼 `Improvement` ADS Sensitivity now smoothly lerps while you aim
- Previously it was binary, no smoothing.

### ❗ `Change` Changed Armory Select UI Controls
- On PC a single click now equips the item.
- On PC a double click now clears the items notifications.
- On PC press Tab to "Go Back".

### ❗ `Change` Removed "Equip" button in Armory Selection UI. Clicking a weapon now auto-equips it

### ❗ `Change` Nerfed flash radius of Flashbang by 20%

### ❗ `Change` Nerfed flash radius of Concussion Grenade by 20%
________

## 🐛 Bugfixes
- Fixed a bug preventing bots from meleeing.
- Fixed a bug causing you to spawn in LOS of an enemy player.
- Fixed a bug where enemy players could display as teammates.
- Fixed a bug where you couldn't see other players gun camos.
- Fixed a bug where you could get soft-locked in a predator missile.
- Fixed a bug where picking up a gun can change its firemode.
- Fixed a bug where you would get stuck on low-health and not regenerate.
